# SaaS v5.3 画布与提示词功能规则总结

整理日期：2026-09-15
范围：画布小地图、整理画布、蚂蚁线、选中框、3%／5% 缩放比例、输入框放大、保存提示词弹窗、提示词库、画布缩放速度。

本文依据现有项目交互约定、专项文档与相关实现整理，作为本轮功能说明与规则汇总；本次未重新运行测试或进行浏览器验收。尺寸默认以 px 表示，涉及画布内容的间距、描边另按画布坐标说明。

## 一、功能概览

| 功能 | 本轮功能点 | 核心规则 |
|---|---|---|
| 画布小地图 | 查看全局分布，快速定位内容 | 等比灰色缩略图；导航只改变位置，不改变倍率 |
| 整理画布 | 根据关联关系自动排版并适应屏幕 | 整理全部内容；组内 80、组间及行间 120 |
| 蚂蚁线 | 高亮当前选中内容的连接关系 | 任一端选中即高亮流动；两端未选中恢复灰色实线 |
| 选中边框与元素加减选 | 统一单选、多选及混合选区反馈 | 所有选中边框固定屏幕 2px；Shift 点击加选／减选 |
| 新增 3%／5% | 扩大画布缩小范围 | 最低 3%；菜单勾选跟随实际倍率 |
| 输入框放大 | 在大尺寸编辑区编写提示词 | 四角拉伸；内容实时同步；关闭保留编辑 |
| 保存提示词弹窗 | 保存前命名，统一气泡样式 | 280 宽顶层气泡；名称必填、最多 50 字 |
| 提示词库 | 管理、应用提示词及查看关联图片 | 本地持久化；支持新增、编辑、删除；图片归属严格匹配 |
| 画布缩放速度 | 统一缩放节奏和各图层同步 | 直接操作实时响应；固定倍率切换用 200ms ease-out |

## 二、画布小地图

### 功能说明

在右下工具组打开画布概览，查看图片和编辑节点的位置分布，通过小地图快速移动当前视窗。

### 交互规则

1. 按内容的真实坐标和尺寸等比投影，保留长宽比例、相对距离及重叠关系，使用中性灰色轮廓，兼容深浅主题。
2. 概览范围包含全部内容与当前可视区域；灰色可视框对应画布当前真实视窗，随平移、缩放、窗口尺寸与节点变化更新。
3. 拖动可视框直接平移画布，保留按下时的抓取偏移；点击框外将视窗定位至点击处，并可继续拖动。整个过程保持缩放比例不变。
4. 拖动期间固定小地图的投影范围，避免内容边界变化导致拖动漂移；松手或取消后恢复正常更新。
5. 支持方向键导航，每次按对应方向移动可视区域尺寸的 10%。
6. 小地图在触发按钮正上方居中展开；窄屏随工具组位置避让。
7. 开关使用独立 ToggleButton，可与网格吸附同时开启。选中时使用 `Alpha/Brand/20%` 底色和 `Text/brand` 图标，悬停保持选中样式。

### 关联导航反馈

画布有内容、但当前视窗与所有节点完全无交集时，显示「当前视窗没有节点，可点击按钮快速回到内容区域」及「回到节点」。点击按全部内容边界适应视窗；空画布或任意节点部分可见时不显示。

## 三、整理画布

### 功能说明

一键整理全部图片和编辑节点，让有来源关系的内容靠近排列，并根据当前可用显示区域选择布局，完成后自动适应屏幕。

### 排列规则

1. 整理范围为全部内容，不受当前选区限制，包含视窗外节点及空编辑节点。
2. 原图、各级抠图结果、编辑节点及演示生成结果按现存来源关系归为关联组；来源不存在时不补建虚拟关系。
3. 关联组放左侧，无来源关系且无编辑节点的独立图片集中放右侧，两区间距为 **240 画布单位**；仅有一个区时不预留另一区。
4. 组内按真实连接分层：同源编辑器同列上下排，结果在下一层，后续编辑器继续向右。层宽取最宽节点，列边界间距 **80 画布单位**；父节点与后代区域垂直居中。
5. 子分支、同行组间及换行间距均为 **120 画布单位**。
6. 只对关联组的外部排列和独立图片区比较列数；组内列数由连接深度决定，不将同源分支横向网格化。相同内容和窗口尺寸得到一致结果。
7. 保留图片尺寸、比例、内容、节点配置、连接关系及选中状态。整理分组只用于排版，不创建永久分组。
8. 整理使用自身间距，不套用拖拽时的 32 单位网格吸附。

### 适应与撤销规则

- 整理改变节点位置，并记录一次可撤销／重做操作；视图变化不计入节点历史，撤销整理不会恢复旧镜头。
- 整理结束后按全部内容联合边界适应安全显示区域，倍率限制为 **3%～100%**。
- 适应屏幕只调整视图，不修改节点位置；若内容跨度在 3% 下仍超出区域，则保持 3% 并居中。
- 安全显示区域预留固定工具栏和顶部内容的空间；临时浮层展开不改变适应边界。
- 拉伸窗口时保持倍率及视窗中心对应的画布坐标，不自动整理；再次点击适应屏幕才按新尺寸重算。

## 四、蚂蚁线与图层展示

完整规则及验收场景见 [蚂蚁线与图层展示规则](canvas-connections-and-layers.md)（2026-09-16 更新）。

### 连线来源

| 类型 | 连接关系 | 来源字段 |
|---|---|---|
| 编辑器输入 | 实际主图 → 编辑器 | editorSourceId；兼容旧记录自带的 fusion |
| 生成结果 | 实际执行生成的编辑器 → 直接结果 | generatedByEditorId |
| 抠图结果 | 实际执行抠图的图片 → 抠图结果 | sourceImageId |

同一主图可以连接多个独立编辑器，每个编辑器可以有多个直接结果。从生成结果再抠图时，只新增“该结果图 → 抠图结果”，不继承生成编辑器关系。再次抠图形成逐级图片来源链。旧记录同时存在 sourceImageId 和 generatedByEditorId 时，抠图来源优先；渲染、整理、关联置顶和编辑器直接结果识别均遵循此规则。

只连接现存端点，不根据名称猜测来源。删除任一端隐藏对应连线，撤销恢复有效关系后重新显示。

### 高亮范围

| 连线 | 触发高亮的选择 |
|---|---|
| 主图 → 编辑器 | 选中该主图或该编辑器 |
| 编辑器 → 直接生成结果 | 选中该编辑器、该结果图，或该编辑器的实际主图 |
| 来源图片 → 抠图结果 | 选中该来源图片或该抠图结果 |

选中主图时，它连接的编辑器输入线和这些编辑器的直接结果输出线一起高亮。选中某个编辑器时，只高亮自身输入及全部直接输出，不把同源其他编辑器的线一起点亮。结果图若又作为主图使用，同时按主图规则展示它的后续编辑器及直接输出线。多选取各自范围的并集，不递归高亮整条来源链。

关联内容置顶和连线高亮是两个独立判断：同组图片被升层，不代表它的所有连线都变成蚂蚁线。没有满足高亮条件的线为灰色实线。

### 图层顺序

以下由前到后，仅比较画布世界内的内容：

| 层级 | 内容 |
|---|---|
| 4 | 高亮蚂蚁线及其暗色底线；同一条线内，主题色虚线在暗色实线上方 |
| 3 | 当前选中的图片／编辑器；选中编辑器时，实际主图及它全部直接生成结果也进入此层 |
| 2 | 与当前选择通过有效关系连接的其余图片／编辑器 |
| 默认 | 其他无关图片／编辑器 |
| -1 | 未高亮的灰色实线 |

关联范围包含现存图片来源链、编辑器主图关系和生成结果关系。同层保留原有绘制顺序，不额外根据最近点击排序。切换或取消选择后重新计算临时层级，不改保存的数组顺序、节点位置或选区；提升层级不会让关联内容自动变成选中状态。

固定工具栏、选区工具栏、菜单与弹窗仍在画布内容之外的更高层。连线保持 pointer-events: none，不能挡住点击、拖动、表单输入或按钮操作。

### 线条外观与端点

| 项目 | 规则（屏幕尺寸） |
|---|---|
| 高亮虚线 | Border/brand，宽 2px，段长 8px，间隔 6px |
| 高亮底线 | 宽 4px，#111817 暗色实线，圆头；深浅主题同色 |
| 普通连线 | Border/medium，宽 2px，无暗色底线 |
| 端点空隙 | 连线两端与各自连接边缘留 2px，含暗色圆头的外伸尺寸 |

画布缩放时反向补偿线宽、虚线间距和端点空隙，保持屏幕上的尺寸。端点仍按两端中心的左右关系连接图片／编辑器的侧边中点，曲线由两端实际坐标计算，拖动实时跟随。

仅将起止点向外偏移，不使用整张图片／节点的遮罩。高亮线中段即使经过其端点图片、编辑器或其他图片内部，也必须保持连续并显示在其前方；不能因为端点避让把中段裁断。此规则不意味着避开所有图片的自动绕线路由。

虚线流动为 800ms linear 无限循环，颜色切换沿用 200ms ease-out。直接拖拽时几何实时更新；开启系统减少动态效果时停用流动，保留静态高亮。

## 五、选中边框与元素加减选

### 选择反馈

| 选区内容 | 选中样式 | 顶部工具栏 |
|---|---|---|
| 一张图片 | 图片自身选中描边 | 单图工具栏 |
| 多张图片 | 联合边界蓝色虚线框＋20% 蓝色蒙版 | 多图工具栏 |
| 单个编辑节点 | 节点自身选中描边 | 不显示图片工具栏 |
| 图片与编辑节点混选，或多个编辑节点 | 全部选中元素的联合边界框与蒙版 | 不显示图片工具栏 |

### 交互与描边规则

1. 选择工具支持空白框选、Shift 点击加选／减选与整组拖动。按住 Shift 点击未选元素加入选区，点击已选元素只移除该元素，保留其他选中；加减选不改变元素位置或内容。抓手工具或按住空格用于平移画布。
2. 批量上传后自动选中本批图片；撤销／重做同步恢复内容及选区。
3. 图片、编辑节点自身选中边框及多选选区边框始终保持 **2px 屏幕粗细**；画布缩放只改变边框位置与尺寸，不改变粗细。50%、100%、200% 下均显示 2px。
4. 图片描边使用 `Border/brand`，图片圆角为 16；选中描边通过独立圆角覆盖层显示，不拦截事件。
5. 编辑节点选中时将原有弱描边设为透明，避免两层描边叠加。
6. 图片工具栏位于选区上方 16px，随视图和选区同步定位。
7. 混合选区整组移动时，各元素使用相同位移，保持相对位置，并支持撤销／重做。
8. 加减选后重新计算选区边界、工具栏及连线高亮；减到空选区时清除边框和选区工具栏。仅按下／松开 Shift 不改变选区，输入、菜单或弹窗操作不误改画布选区。

## 六、缩放比例新增 3% 与 5%

### 功能说明

在固定倍率菜单中增加 5% 和 3%，方便查看大范围画布内容。

### 菜单与倍率规则

- 菜单顺序：**200% → 100% → 50% → 30% → 10% → 5% → 3% → 适应屏幕**。
- 手动缩放范围为 **3%～400%**；「适应屏幕」范围为 **3%～100%**。
- 勾选状态跟随真实倍率，不固定停留在上一次点击的选项；显示百分比可以四舍五入，视图计算保留精度。
- 选择固定倍率以当前视窗中心为缩放锚点，切换动效见第十节。
- 点击外部或按 Escape 关闭菜单；展开箭头根据菜单是否打开变化，不由焦点状态决定。

### 样式规则

| 项目 | 规格 |
|---|---|
| 缩放控件 | 144 × 40 |
| 菜单 | 112 × 300，圆角 12，内边距 8 |
| 菜单位置 | 控件上方 4px，水平居中 |
| 条目 | 高 32，条目间距 4 |
| 选项反馈 | `State/hover` 底色、`Text/brand` 文字、组件库原始勾号 |
| 百分比框聚焦／展开 | `Control/fill/focus` 底色＋1px `Border/brand` 描边 |

## 七、输入框放大

### 功能说明

将节点提示词输入区展开为大尺寸编辑区，方便输入和阅读长提示词。

### 交互规则

1. 点击提示词区放大按钮打开编辑器，默认输入区域为 **960 × 640**，背景使用遮罩及 **50px 模糊**。
2. 支持拖动四个角实时调整大小，最大输入区域为 **1280 × 720**；受当前视窗限制，小窗口自动收敛尺寸和位置。
3. 内容上限为 **2000 字**；展开区与原节点使用同一份文本，编辑实时同步。
4. 按 Escape、点击空白背景或点击收起按钮退出；关闭后保留已经同步的文本。
5. 放大编辑器内可继续保存提示词或打开提示词库。
6. 从放大编辑器进入提示词库时，编辑器保持挂载，保留文本、大小及位置；关闭提示词库只返回编辑器，应用提示词后更新编辑器内容。
7. 编辑与拉伸操作隔离画布事件，避免误触节点拖动或画布平移。

## 八、保存提示词弹窗样式优化

### 功能说明

点击保存后先通过命名气泡输入提示词名称，保存为独立记录，便于在提示词库中识别与复用。

### 样式与交互规则

1. 使用 **280px 宽**顶层气泡，内边距及主要内容间距为 **16px**；包含标题、关闭按钮、名称输入框及取消／保存操作。
2. 气泡优先显示在触发按钮上方，空间不足时显示在下方，并限制在视窗内；在放大编辑器中打开时也保持顶层可见。
3. 提示词内容为空时不进入命名流程，提示「请输入提示词后再保存」。
4. 名称必填，最多 **50 字**，显示实时计数；纯空白名称不可保存。
5. 支持点击保存及有效名称下按 Enter 保存。点击取消、关闭、外部区域或 Escape 退出命名，不新增记录。
6. 每次保存创建新的独立 ID；即使文本相同，也不继承其他提示词记录的关联图片。
7. 保存成功后关闭气泡并更新提示词库；本地存储失败时显示失败反馈，不当作保存成功。
8. 纯图标按钮保持正方形尺寸并使用组件库 Tooltip；鼠标打开／关闭弹窗不出现额外键盘焦点圈，Tab 导航保留焦点反馈。

## 九、提示词库

### 功能说明

集中管理提示词，支持搜索、查看详情、新增、编辑、删除及应用，并在有匹配记录时展示关联图片。

### 布局与入口

- 标准弹窗尺寸为 **1280 × 800**，左侧列表与搜索区域宽 **320px**，右侧用于详情、编辑和应用。
- 可从节点直接打开，也可从放大编辑器打开。
- 从节点打开，退出返回画布；从放大编辑器打开，关闭／Escape／应用仅关闭提示词库，返回仍然保留的编辑器。
- 使用 Lightchain SaaS v5.1 libraries Beta 输入组件及语义颜色，兼容深浅主题。

### 新增、编辑与删除

1. 点击新增后，在列表顶部创建临时卡片并立即选中，清空搜索并滚动到顶部。
2. 空卡片显示 `Untitled`／「请输入提示词内容...」占位提示，占位文字不作为实际内容保存。
3. 草稿输入实时更新卡片预览；名称及内容均必填，上限分别为 **50／2000 字**，显示计数。
4. 新建表单名称使用 40px 高 Input L，正文输入区圆角为 16。
5. 保存时沿用草稿 ID，不重复生成卡片，也不附带其他记录的关联图片。
6. 取消或删除未保存草稿时移除临时卡片，恢复此前选择；不删除已有条目。
7. 已保存记录的编辑页底部左侧显示危险色「删除」，右侧保留取消／保存。
8. 删除成功后选择下一条可用记录，提示词库保持打开；删除提示词不删除画布图片。
9. 已保存卡片的更多菜单支持置顶／取消置顶与删除；置顶记录排在普通记录之前，最近置顶的记录排在前面，置顶状态本地保存。

### 应用规则

- 可覆盖当前提示词，或追加到已有文本之后；追加时用换行分隔。
- 合并后超过 2000 字时不应用，提示精简原文或选择覆盖。
- 应用成功后更新当前节点／放大编辑器文本，并关闭提示词库。

### 关联图片规则

1. 关联图片为 **144 × 144** 正方形，间距 **8px**；右上角显示 24px 高「主图／AI生成」标记。
2. 有关联图片时，提示词内容区为 280px，图片区域独立滚动；没有匹配记录时，整个关联图片区隐藏。
3. 必须同时匹配 **提示词 ID＋生成时的完整提示词快照**，才展示该条记录的关联图片。
4. 修改提示词内容后，旧快照不再匹配；另存为新提示词即使文字相同，也不继承原条目的图片。
5. 当前关联图片来自已配置的三组演示记录；生成后端未接入，尚不代表已自动采集真实生成历史。

### 持久化规则

- 数据保存在当前浏览器本地，同一浏览器内的节点共享提示词库。
- 兼容将旧字符串和旧数组数据迁移为带名称、内容和 ID 的记录。
- 新版存储采用 `{version:2, entries:[...]}`；删除的演示记录不会在刷新后重新补入，包括删除全部记录的情况。
- 迁移时按稳定 ID 合并演示记录，保留已有用户条目。

## 十、缩放画布速度与同步

### 功能说明

区分直接镜头操作和点击固定倍率的切换，让画布操作及时响应，同时保持图片、节点、点阵和选区同步移动。

### 操作规则

| 操作 | 响应方式 | 缩放锚点／位置规则 |
|---|---|---|
| Option（Mac）／Alt（Windows）＋滚轮、原有 Ctrl／Command＋滚轮，以及浏览器映射为 Ctrl 滚轮的捏合手势 | 实时缩放，不附加缓动 | 围绕指针位置 |
| 普通滚轮／触控板滚动 | 按输入位移实时平移 | 不改变倍率 |
| 百分比菜单选择固定倍率 | **200ms ease-out** | 保持当前视窗中心对应的画布位置 |
| 连续选择不同固定倍率 | 从当前显示状态继续新的 200ms 过渡 | 不跳回上一次过渡起点 |
| 过渡期间进行滚轮、平移或小地图导航 | 取消未完成过渡，立即接管视图 | 跟随当前直接操作 |

### 速度参数与同步规则

1. 当前滚轮缩放按输入量连续计算：`目标倍率 = 当前倍率 × exp(-deltaY × 0.005)`，再限制在 **3%～400%**。向上放大，向下缩小；变化幅度取决于设备输入量，不固定每格增加若干百分点。
2. 固定倍率切换使用共享视图逐帧插值，曲线为 `cubic-bezier(0, 0, 0.58, 1)`，持续 **200ms**。
3. 图片、编辑节点、点阵、选中框及小地图读取同一份逐帧视图状态，避免某一层延迟跟随。
4. 图片层与点阵使用相同的画布变换；不能再给其中一层单独添加 CSS transform 过渡。
5. 点阵的点大小和间距随倍率一起缩放：100% 时点半径为 1、间距为 32 画布单位；平移同步跟随画布。
6. 系统开启减少动态效果时，固定倍率切换立即完成；直接拖动、平移仍实时跟手。
