# 视频模版生成

模版由后台人工维护。每个模版记录使用的节点功能、输入素材及字段映射、描述和生成设置；详情标签显示实际节点名称。

## 使用规则

- 「立即生成」要求商品图、模特图至少替换一项；「编辑模版」允许直接使用原始模版。素材读取或提交期间禁用操作，防止重复提交。
- 上传商品图后，用该图替换模版商品组；未上传商品图则保留原商品组全部图片。模特图独立按同样规则处理。
- 点击「编辑模版」后收起弹窗，画布追加输入图片、对应功能节点及现有示例结果，并建立输入到节点、节点到结果的连线。节点图片与画布输入一致，描述及设置来自模版；不创建生成任务。
- 点击「立即生成」后收起弹窗，画布只追加结果的loading占位，不创建输入图片或功能节点。占位按提交时的生成比例计算，竖图宽360px、横图高320px，另一边按比例计算；Auto跟随实际首张输入，无输入时为1:1。
- 两个操作均避开已有内容并聚焦新增内容，整次操作可一次撤销。生成完成后原位替换占位，保留ID与位置；视频尺寸改按原文件实际比例，竖向固定宽360px、高度自适应。任务列表支持点击聚焦；独立结果任务不依赖画布编辑器存在。
- 画布视频封面铺满素材框，不因封面比例与视频比例的细微差异留白。博主种草原视频1124×1844，画布尺寸约360×590.60px；模版设置的3:4用于生成中占位，不改变演示原文件。
- 切换模版、关闭弹窗或离开工作台时，取消尚未完成的素材准备；读取失败不创建残缺节点。

## 当前演示配置

电商视频和品牌故事均使用专业服装视频节点。两套模版保留现有 2K、10s 设置，分别为 9:16 和 16:9；生成模式配置为支持 2K 的快捷模式。节点功能名称与节点内部的生成模式为不同字段。

博主种草使用用户于2026-10-26提供的视频与图片，存放于 `public/assets/video-template-creator/`，原文件不转码、不裁切。视频用于模版预览及生成演示结果，图片作为封面和唯一默认人物参考图。参数为3:4、5s、720p，使用专业服装视频节点的专业模式。上传商品图时将其加入参考素材并保留原人物图；上传人物图时替换原人物图。素材区只展示一张原图，不重复凑商品与人物缩略图。

模版定义位于 `src/video-templates.ts`，字段映射及实例创建位于 `src/video-template-generation.ts`。现有两套描述为本地演示配置，后续可替换为后台维护的正式描述。

生成复用本地演示任务，约 3 秒后显示对应模版的预览视频，不根据上传素材实时合成视频。未接后台模版接口、真实生成服务或扣费。
