# 项目封面

## 范围与入口

适用于万能穿搭融合和视频工作台中的有效图片和视频素材，封面用于项目列表。图片使用原图，视频使用已有封面帧，不另选图片或截取新帧。

- 右键图片或视频素材，菜单顺序为：下载 → 分隔线 → 复制 → 复制并粘贴 → 设为项目封面／恢复默认封面 → 分隔线 → 删除。
- 视频工作台素材右键菜单最上方增加「下载」，点击下载选中素材：单个下载原文件，多个打包 ZIP；视频下载原视频。生成中、失败占位不参与下载。
- 封面操作只针对右键点击的素材，多选时不批量设置。
- 生成中、失败占位不提供封面操作。

## 设置封面

- 普通素材显示「设为项目封面」。点击后，使用该素材作为项目封面，并提示「已设为项目封面」。
- 首次成功设置项目封面前，封面操作显示 NEW；首次设置成功后不再显示。使用状态按用户记录，图片、视频及不同 Flow 画布共用。
- 仅打开菜单或设置失败不计为成功；恢复默认、删除封面或撤销不重新显示 NEW。
- 每个项目只保留一张手动封面，新设置替换原设置。
- 手动封面素材左上显示「封面」标签；自动选取的默认封面不显示标签。
- 已设置手动封面时，新添加或生成的素材不替换封面。

## 恢复默认封面

- 当前手动封面素材的菜单显示「恢复默认封面」。点击后取消手动设置，并提示「已恢复默认封面」。
- 未设置手动封面、恢复默认或删除手动封面素材时，使用画布中最新的有效素材。
- 添加、复制的素材按加入时间排序；生成素材按成功完成时间排序。同批素材取最后一个。
- 没有有效素材时，使用系统默认封面。

## 撤销与复制

- 设置、恢复和删除支持现有撤销重做，恢复对应的封面状态。
- 复制素材不继承原素材的手动封面身份。

## 数据埋点

| 事件 | 触发时机 | 记录内容 | 统计用途 |
| --- | --- | --- | --- |
| 设置项目封面 | 用户点击「设为项目封面」，设置返回成功或失败时记录一次。 | 用户 ID、项目 ID、画布类型、素材 ID、素材类型（图片／视频）、操作时间、结果（成功／失败）。成功时记录是否为该用户首次设置成功；失败时记录失败原因。 | 使用人数、设置次数、成功率、首次使用人数及图片／视频占比。 |

恢复默认封面、删除后自动回退及撤销重做，不计入「设置项目封面」事件；仅打开右键菜单不记录。

## UI 与 Demo 边界

当前 Demo 尚未接入埋点上报。

素材右键菜单按 [Figma 5:4470](https://www.figma.com/design/A3oI9FzDPseUH4ybk7mA3H/Lightchain-SaaS-v5.6.0?node-id=5-4470&m=dev) 展示，画布素材上的「封面」标签已按 [Figma 5:7906](https://www.figma.com/design/A3oI9FzDPseUH4ybk7mA3H/Lightchain-SaaS-v5.6.0?node-id=5-7906&m=dev) 接入。

- 中文 Mac 完整菜单为 224×226px；内边距及组间距 8px，行高 32px，图标 20px，正文 14/20px。
- 快捷键使用 12/16px Medium 灰色文字，放在高 20px 的圆角标签内；Mac 显示 ⌘，其他平台显示 Ctrl。
- 封面操作右侧的 NEW 标记为高 20px 的渐变胶囊形，首次成功设置项目封面后隐藏。
- 下载后和删除前显示分隔线；使用浮层背景、弱边框及 L 级阴影，沿用深浅主题语义 token。现有菜单行为保持不变。
- 「封面」标签使用 `Badge/Text/Rounded`：中文 32×20px，高 20px，左右内边距 4px，圆角 4px，无图标。文字为 Noto Sans SC Regular 400、12/16px，使用白色 `Text/on-brand-white`；背景使用黑色 75% 的 `Surface/floating-strong`，深浅主题颜色一致。标签位于素材左上角，距顶部及左侧各 8px，并随素材缩放。

Demo 仅在本地会话中保留封面状态，未接入服务端保存或项目列表。画布内可查看手动封面标签；融合画布沿用现有项目摘要展示封面，视频工作台暂未提供项目摘要入口。

Demo 的 NEW 使用状态由同一浏览器的 localStorage 记录，使用 `lc-v56-` 前缀；两个画布、刷新及同源标签页同步，不属于账号级或跨设备存储。
