# 画布整理与适应屏幕：开发交付规则

版本：2026-10-26。适用于 v5.6 万能穿搭融合与视频工作台的 Flow 画布。产品规则见 [Flow 画布整理规则](flow-canvas-arrangement-rules.md)，视频快照字段见 [视频工作台整理规则](video-canvas-arrangement.md)。本文区分画布坐标与屏幕 CSS 像素；不以物理像素或设备 DPR 计算布局。

## 1. 两个动作的区别

| 动作 | 改变节点坐标 | 改变视图平移／缩放 | 作用范围 |
|---|---|---|---|
| 整理画布 | 是 | 整理结束后自动适应屏幕 | 全部图片及编辑节点，不局限当前选区 |
| 适应屏幕／回到节点 | 否 | 是 | 全部图片及编辑节点的联合边界 |
| 拉伸浏览器窗口 | 否 | 保持倍率，平移以保持中心内容 | 当前视图 |

图片原始比例、尺寸、节点配置、连接关系及选中状态保持不变。整理记录一次历史，可撤销／重做节点位置；视图移动不计入节点历史，撤销不会恢复旧镜头。

## 2. 关联分组与间距

组归属确定后，按组内实际连接重新排版，不按“旧组＋新增内容”横向拼接。无上游的新增输入素材放在流程中最靠前的使用节点左一列，与该列已有输入按列表顺序上下排列。例如一键融合结果与花纹图共同输入合拼生图，两张输入同列，合拼节点在右侧居中两张输入，其结果再与节点居中。共享素材只摆放一次，不因后续引用搬过前面的使用节点。

按现存 `sourceImageId`（抠图来源）、`editorSourceId`（编辑节点主图）、`generatedByEditorId`（演示结果所属编辑节点）建立关系。图片和编辑器分别作为可见节点；同一图片自带的旧版编辑器也单独参与排版。不存在的来源不补建虚拟关系。抠图结果以 sourceImageId 为唯一直接来源，即使旧记录残留 generatedByEditorId，也不连接生成编辑器。连线高亮与临时置顶详见 [蚂蚁线与图层展示规则](canvas-connections-and-layers.md)。

多输入编辑器以输入列表的 `sourceImageId` 连接画布图片；批量编辑使用 `mainImages`，共享 `references` 不参与归组，合拼及批量转3D平铺沿用 `references`。URL 不参与连接身份判断。缺失来源忽略，同一来源只收纳一次。输入按列表顺序竖排，编辑器在右侧并相对整组输入居中，结果及后续步骤继续向右。

尚未确定节点组的主图优先保留仍有效的 `layoutTaskId`；原归属缺失或失效时，归属当前引用它且创建最早的多输入编辑器。输入来自一个已有组时，新编辑器及新图并入原组；来自两个以上已有组时，新编辑器及新图另成一组。所有输入均为独立素材时直接组成新组。旧图保留唯一归属，以跨组连线引用，不复制或搬走原组图片。

组间按主图上传顺序排列；多主图新组取最早主图的上传序，已有组追加图片或节点保持原组顺序。生成结果沿用原主图的上传序，多轮生成继续继承；批量编辑逐张结果继承对应主图，合拼单结果取实际主图来源的最早值，共享参考图不参与。跨组依赖先上游、后下游。

每张画布图片用 `layoutOriginOrder` 保存排序依据：上传图记录会话加入序，生成结果在生成时固定继承值，之后换输入或删除来源不重算。该值随画布快照撤销／重做；旧数据缺少字段时，在来源仍可解析的情况下回填。新素材单独分配加入序，不由它在数组中的位置决定。

生产保存恢复需保留图片 ID、连接、主图列表顺序及 `layoutOriginOrder`。当前 Demo 仅在会话和撤销历史内保留，未实现服务端画布项目持久化。

普通组与跨组下游组共同参与排序。按组顺序依次安排，尚未排列的上游先行；阶段只向右推进，后上传素材形成的新独立组接在已有下游之后，不返回最左阶段。例：已有 A、B → C，再新增独立 D，整理后为 A、B → C、D。

关联组位于上方，跨组任务按依赖阶段向右延伸；未关联图片和空节点集中放下方，两区间距 480。只有一个区时不预留空区。普通编辑器宽 280，批量编辑器为 592×404；尺寸由 `workflowWidth`／`workflowHeight` 按类型和内容统一计算，连线、选区、小地图、整理和适应使用同一几何。图片尺寸与比例不变。

## 3. 按真实连接层级整理

```text
主图 → 编辑器 A → 结果 A
     → 编辑器 B → 结果 B → 后续编辑器 → 后续结果
     → 编辑器 C → 结果 C
```

- 每条真实连接推进一层；同源编辑器上下排列在同一列，结果位于下一层。列数随连接深度延伸，不设固定上限。
- 同层内容不能为了适应视窗横向换列，否则会把并列分支误排成连续步骤。已取消此前在组内枚举分支列数的网格方案。
- 每层宽度取该层最宽节点，输入到编辑器、编辑器到结果的列间距统一为 80，包含合并生图、批量编辑等多输入节点。窄节点到下一列的实际空隙可能更大。
- 多个后续节点或结果按创建顺序上下展开，纵向间距至少 120；父节点对齐直接连接对象的实际整体中心，不以整片后代区域或虚拟占位计算。每条单线流程共用水平中心线。
- 汇合节点按直接连接的实际输入整体居中，未连接素材不参与。单个结果跟随编辑器居中，多个结果按整列中心对齐；不同大小的素材使用真实尺寸。
- 共享素材只摆放一次；跨组输入保留旧组位置，下游按实际引用素材定位。先保证关系、归属与唯一性，再保证不重叠，最后满足居中。发生重叠时，后排分支或组整体向下避让，内部相对位置保持，此时允许偏离上游中心。
- 20 个同源编辑器会增加纵向跨度；只有下游步骤增加横向层级。不会复制主图，也不修改连接关系来压缩布局。
- 关联组按顺序从左到右排列，每行最多 5 组，第 6 组起换行，每组保持完整。同一跨组依赖阶段与下方独立区分别遵循每行最多 5 个。同行组间、换行间距 240；关联区与下方独立区、跨组依赖阶段之间间距均为 480。
- 换行数量不随窗口尺寸变化；没有跨组输入对齐约束时，每行按最高组计算行高，各组整体中心位于同一条水平线。较矮组向下偏移「（行高 − 组高）÷ 2」，组内相对位置保持不变；下一行从左侧开始。有跨组输入时优先按实际输入范围居中，再处理避让。下方独立区及批量上传初始摆放保持原布局。相同内容重复整理位置不变，返回数组保留原数据顺序。
- 整理起点 `(0,0)`，完成后适应全部内容；记录一次撤销／重做。分组只用于位置，不创建永久分组，不使用 32px 拖拽吸附。

批量上传时仅自动摆放本批新内容，每行最多 5 张，第 6 张起换行；同批图片的横向、纵向间距为 40px（画布坐标，随视图缩放）。起点为现有节点最右边缘加 240，不移动旧节点。这是上传后的初始摆放，不是多选整理入口。

## 4. Web 可用显示区域

W／H 取画布元素的 `clientWidth`／`clientHeight`，不取整个浏览器窗口高度；48px 顶栏已在画布外扣除，不能重复减去。

可用区域为 `(L, T, W-L-R, H-T-B)`，取值单位为屏幕 CSS px：

| 预留 | W > 1100 | 680 < W ≤ 1100 | W ≤ 680 |
|---|---|---|---|
| L 左侧 | min(96, W×0.20) | 同左 | 同左 |
| R 右侧 | min(32, W×0.10) | 同左 | 同左 |
| T 顶部 | min(176, H×0.35) | 同左 | min(224, H×0.35) |
| B 底部 | min(88, H×0.25) | min(144, H×0.25) | min(144, H×0.25) |

区域宽高至少为 1。此预留对应现有固定项目卡、折叠智能搜索、侧栏、底部工具栏，以及图片选中工具栏上方空间。≤1100px 时底部工具分行，增加底部预留；≤680px 时顶部搜索换行，再增加顶部预留。

临时展开的小地图、下拉菜单、搜索内容、Tooltip 和上传弹窗不改变适应边界，避免打开浮层时画布跳动。窗口极小时预留按比例压缩，仅保证几何计算有效；不能承诺所有固定控件都不遮挡，此时需折叠辅助面板或增大窗口。后续产品固定工具栏尺寸／位置变化时，应同步更新预留规则。

## 5. 适应屏幕算法

包含所有图片和编辑节点，包括视窗外、未选中、独立移动过的编辑节点；不包含连线、阴影、临时浮层和选中工具栏本身。

设联合边界左上角 `(Bx, By)`、宽高 `(Bw, Bh)`，可用区域左上角 `(Ax, Ay)`、宽高 `(Aw, Ah)`：

```text
s = clamp(min(Aw / max(Bw, 1), Ah / max(Bh, 1)), 0.03, 1)
tx = Ax + Aw/2 - (Bx + Bw/2) × s
ty = Ay + Ah/2 - (By + Bh/2) × s
screenX = worldX × s + tx
screenY = worldY × s + ty
```

内容居中于可用区域，不是直接居中于包含固定工具栏的整个浏览器。适应最多 100%，避免将小图片自动放大；用户可用手动缩放继续放大至 400%。计算保留浮点精度，仅百分比文案四舍五入。

最低倍率沿用现有 3%。**当内容跨度在 3% 下仍超过可用区域时，保持 3% 并居中，不保证一次展示全部内容。** 这是 Demo 当前的边界，生产若要求任意规模都完整显示，应统一调整手动缩放和适应的最小倍率，不能只改其中一处。

空画布不显示整理入口；几何函数的空输入返回默认视图 `(tx=0, ty=0, s=1)`。单节点仍沿用同一公式。画布镜头适应立即同步，普通控件状态切换沿用 `200ms ease-out`。

## 6. 浏览器窗口变化

通过 `ResizeObserver` 监听画布实际尺寸，包含浏览器拉伸、侧边面板改变可用宽度等情况。

窗口从 `(W₀,H₀)` 变为 `(W₁,H₁)`：

```text
s₁ = s₀
tx₁ = tx₀ + (W₁-W₀)/2
ty₁ = ty₀ + (H₁-H₀)/2
```

保持画布视窗中心对应的世界坐标和倍率；不自动重排、不修改图片／节点位置，也不持续自动执行适应。即使上次点击过适应屏幕，随后拉伸窗口仍遵循此规则；用户再次点击适应时按新尺寸重新计算。小地图与「回到节点」提示按新视窗同步更新。

## 7. 布局约束与代码入口

- 同源编辑器同列，后续步骤按层向右；组内列间距统一为 80、子分支间距 120、组间距 240。
- 新旧主图属于同一个任务时一起整理；组内依主图列表、组间依主图上传序，跨组依赖优先。一个已有组接收新节点及新图，多个已有组保持原归属并另建新组；尺寸、内容和关系保持不变。
- 窗口宽窄不改变分组、每行数量或连接层级；相同输入多次整理结果一致。
- 适应屏幕只更新视图，正常尺度下全部内容在可用区域内，且不超过 100%。
- 手动移远的编辑节点参与边界计算；回到节点能定位完整内容区域。
- 记录极端跨度达到 3% 下限的例外，不能将其验收为「已完整展示全部」。
- 拉伸窗口保持中心世界坐标及倍率，重新点击适应使用新区域。
- 整理后撤销／重做恢复节点位置；选区不限制整理范围，自动布局间距不使用 32px 手动网格吸附。

实现：`src/canvas.ts`（融合关系解析、适应）、`src/canvas-connected-layout.ts`（共用组内连接布局）、`src/canvas-group-placement.ts`（共用跨组输入约束与放置）、`src/canvas-task-layout.ts`（融合任务归属与顺序）、`src/canvas-layout-stages.ts`（共用阶段排序）、`src/video-workflow-layout.ts`（视频关系解析与整理入口）、`src/video-layout-groups.ts`（视频归属与来源序）、`src/App.tsx`（全画布整理入口、视窗变化、上传及回到节点）。

## 多编辑节点

每次点击主图工具栏的一键融合均创建新的独立编辑记录，用 editorSourceId 指向同一主图；不复制画布图片，不限制节点数量。提示词、参考图和生成设置独立。从素材工具栏创建节点时，新节点放在素材右侧80px，两者垂直中心对齐；多选时，以所选素材整体边界为基准。允许与已有素材或节点重叠，不自动向下避让；需要重排时使用「整理」。此规则同样适用于合拼生图、批量编辑及批量转3D平铺。空节点补回主图时，保持编辑器位置，将主图放在左侧并居中对齐。参考图或融合点增减导致节点高度变化时，围绕原中心伸缩，保留手动拖动产生的相对位置。保留旧版随图片存储的第一个编辑节点兼容。删除主图清空所有关联编辑器，删除一个编辑器不删除主图或其他编辑器。点主图高亮其全部直接连线，点编辑器仅高亮自身连线。

## 演示生成

画布定向融合与内衣试衣节点也已按用户授权接入同一本地示例生成：只需主图／服装图，融合点、试衣描述与模特图可留空；结果名称分别为「定向融合结果 · 演示」「内衣试衣结果 · 演示」。下方指令非空要求仅适用于一键融合。AI试衣独立页流程不变。

主图存在且指令非空时，每点一次生成，追加一张宽360、保持原图比例的对应功能示例图，由 `src/workflow-examples.ts` 统一提供配套结果。名称注明演示，以 `generatedByEditorId` 指向实际编辑节点；不会改成直接归属主图。新图先放编辑器右侧80，遇到已有节点向下找空位；选中新结果，支持撤销／重做。素材与生成提示词见 `docs/workflow-example-images.json`。

结果可继续创建编辑器，形成多级连接；整理、小地图、适应和关联提升包含这些结果。删除编辑器保留结果图片并隐藏失效连接，撤销可恢复。主图选中时高亮其编辑器连接及这些编辑器的结果线；单选编辑器高亮自身输入／输出，单选结果高亮自身输入及其直接后续连接。

批量编辑共用提示词、比例和分辨率；每张主图对应一张固定本地示例结果，以 `generatedByEditorId` 关联节点、`generatedFromReferenceId` 关联该次主图，结果放节点右侧 80 并避让已有内容。

这只是用户授权的交互演示，不调用 AI，不扣费，不创建真实生成任务或提示词历史。空节点先要求添加主图，空指令沿用必填提示。本轮批量编辑及整理改动未运行检查、构建或浏览器验证。
