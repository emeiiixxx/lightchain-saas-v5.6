# 画布复制与粘贴

- Mac 使用 Command+C / Command+V，Windows 使用 Ctrl+C / Ctrl+V。支持单选及图片、节点混合多选。
- 图片副本保留图片内容、名称和尺寸，作为独立图片；不继承编辑器、生成来源或抠图来源连线。
- 节点副本不带主图，保留参考图、提示词及生成设置；不复制生成结果，不继承旧连线。补充主图后可继续使用。
- 即使同时复制主图和节点，两个副本也保持独立，不自动建立主图关联。
- 粘贴自动选中新副本，保留多选元素的相对位置。每次向右下偏移 32 屏幕像素；原位置已移出视窗时，将副本放回当前视窗。
- 每次粘贴可整批撤销／重做。复制时保存内容快照，之后修改原节点不影响待粘贴内容。
- 输入框与可编辑文字保持原生复制／粘贴；弹窗、菜单及画布参考图选择期间不复制画布元素。
- 右键画布空白处显示「上传图片／粘贴」，粘贴右侧按系统显示 ⌘+V 或 Ctrl+V。未复制画布元素时粘贴禁用；菜单粘贴将副本左上角放在右键位置。
- 双击画布空白处围绕鼠标放大 1.25 倍，最大 400%；不再触发上传。图片、节点及浮层内双击不触发此操作。
- 当前支持同一页面会话内的画布复制，不读取外部剪贴板图片，不支持跨页面复制节点。
