# 蚂蚁线与图层展示规则

适用版本：SaaS v5.3。更新：2026-09-16。本规则覆盖此前关于连线置顶和整张端点图片遮罩的旧说明。

## 连线来源

| 类型 | 连接关系 | 来源字段 |
|---|---|---|
| 编辑器输入 | 实际主图 → 编辑器 | editorSourceId；兼容旧记录自带的 fusion |
| 生成结果 | 实际执行生成的编辑器 → 直接结果 | generatedByEditorId |
| 抠图结果 | 实际执行抠图的图片 → 抠图结果 | sourceImageId |

同一主图可以连接多个独立编辑器，每个编辑器可以有多个直接结果。从生成结果再抠图时，只新增“该结果图 → 抠图结果”，不继承生成编辑器关系。再次抠图形成逐级图片来源链。旧记录同时存在 sourceImageId 和 generatedByEditorId 时，抠图来源优先；渲染、整理、关联置顶和编辑器直接结果识别均遵循此规则。

只连接现存端点，不根据名称猜测来源。删除任一端隐藏对应连线，撤销恢复有效关系后重新显示。

## 高亮范围

| 连线 | 触发高亮的选择 |
|---|---|
| 主图 → 编辑器 | 选中该主图或该编辑器 |
| 编辑器 → 直接生成结果 | 选中该编辑器、该结果图，或该编辑器的实际主图 |
| 来源图片 → 抠图结果 | 选中该来源图片或该抠图结果 |

选中主图时，它连接的编辑器输入线和这些编辑器的直接结果输出线一起高亮。选中某个编辑器时，只高亮自身输入及全部直接输出，不把同源其他编辑器的线一起点亮。结果图若又作为主图使用，同时按主图规则展示它的后续编辑器及直接输出线。多选取各自范围的并集，不递归高亮整条来源链。

关联内容置顶和连线高亮是两个独立判断：同组图片被升层，不代表它的所有连线都变成蚂蚁线。没有满足高亮条件的线为灰色实线。

## 图层顺序

以下由前到后，仅比较画布世界内的内容：

| 层级 | 内容 |
|---|---|
| 4 | 高亮蚂蚁线及其暗色底线；同一条线内，主题色虚线在暗色实线上方 |
| 3 | 当前选中的图片／编辑器；选中编辑器时，实际主图及它全部直接生成结果也进入此层 |
| 2 | 与当前选择通过有效关系连接的其余图片／编辑器 |
| 默认 | 其他无关图片／编辑器 |
| -1 | 未高亮的灰色实线 |

关联范围包含现存图片来源链、编辑器主图关系和生成结果关系。同层保留原有绘制顺序，不额外根据最近点击排序。切换或取消选择后重新计算临时层级，不改保存的数组顺序、节点位置或选区；提升层级不会让关联内容自动变成选中状态。

固定工具栏、选区工具栏、菜单与弹窗仍在画布内容之外的更高层。连线保持 pointer-events: none，不能挡住点击、拖动、表单输入或按钮操作。

## 线条外观与端点

| 项目 | 规则（屏幕尺寸） |
|---|---|
| 高亮虚线 | Border/brand，宽 2px，段长 8px，间隔 6px |
| 高亮底线 | 宽 4px，#111817 暗色实线，圆头；深浅主题同色 |
| 普通连线 | Border/medium，宽 2px，无暗色底线 |
| 端点空隙 | 连线两端与各自连接边缘留 2px，含暗色圆头的外伸尺寸 |

画布缩放时反向补偿线宽、虚线间距和端点空隙，保持屏幕上的尺寸。端点仍按两端中心的左右关系连接图片／编辑器的侧边中点，曲线由两端实际坐标计算，拖动实时跟随。

仅将起止点向外偏移，不使用整张图片／节点的遮罩。高亮线中段即使经过其端点图片、编辑器或其他图片内部，也必须保持连续并显示在其前方；不能因为端点避让把中段裁断。此规则不意味着避开所有图片的自动绕线路由。

虚线流动为 800ms linear 无限循环，颜色切换沿用 200ms ease-out。直接拖拽时几何实时更新；开启系统减少动态效果时停用流动，保留静态高亮。

## 验收场景

- 一张主图连接多个编辑器，各有多个结果：分别选主图、单个编辑器及单张结果，核对高亮范围，不串亮其他分支。
- 无关图片重叠：选编辑器后，它的主图与全部直接结果在其他关联内容之上，蚂蚁线和底线再高一层。
- 来源图与抠图结果上下摆放或重叠：高亮线中段跨图仍连续，两端保留空隙。
- 从生成结果抠图，再对抠图结果抠图：每次只连接实际来源图片，不误接生成编辑器；整理按同一来源关系排列。
- 低倍率、100% 和高倍率下比较线宽及端点空隙；切换深浅主题，暗色底线保持一致。
- 删除／撤销、切换／取消选择后，连线和临时层级随状态恢复；固定工具栏与输入交互不受影响。
