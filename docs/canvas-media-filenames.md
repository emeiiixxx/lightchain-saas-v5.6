# 画布素材文件名

## 范围

适用于万能穿搭融合和视频工作台中，实际展示在画布上的图片、视频素材。

## 展示

- 素材顶部展示「类型图标＋文件名」，图片与视频使用各自的类型图标。
- 文件名列与素材左侧对齐，总宽度与素材的实际显示宽度一致，包含图标和图文间距。
- 文件名只显示一行，超出可用宽度显示省略号；完整文件名保留。
- 文件名列高16px，距素材8px；图标16×16px，图文间距4px。文字为12px、行高16px、Regular，颜色使用Text/tertiary，随主题切换。
- 文件名列随素材移动和缩放。素材工具栏位于文件名上方，保持16px屏幕间距。

## 命名

- 添加的素材：保留原始文件名及格式后缀。
- 生成的素材：使用「功能名称-YY-MM-DD-编号.格式后缀」。功能名称取实际生成该素材的功能；日期取创建本次生成结果时的本地日期，格式后缀与实际文件格式一致。
- 同一画布、同一功能、同一日期的生成结果，从001开始依次编号。批量结果逐个编号；编号至少3位，超过999后继续增加。
- 不同功能、不同日期分别编号；两种画布各自编号。
- 文件名在生成时固定，任务完成、复制、撤销重做后保留，不因重新渲染或整理画布而变化。

当前 Demo 在画布会话内维护编号，生成文件沿用实际PNG、WebP、MP4等格式；未接入服务端画布存储，不承诺刷新后恢复画布或编号。
