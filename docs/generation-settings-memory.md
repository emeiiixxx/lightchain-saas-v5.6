# R07｜生成设置记忆

## 适用范围

万能穿搭融合画布中的以下四类节点，分别记住最近一次手动修改后的比例和分辨率，互不影响。

| 需求节点 | 当前 Demo 入口 | 类型 |
| --- | --- | --- |
| 一键融合 | 一键融合 | `fusion` |
| 批量编辑 | 批量编辑 | `batch` |
| 批量一键融合 | 合拼生图 | `merge` |
| 定向融合 | 定向融合 | `directed` |

当前 Demo 使用「合拼生图」演示「批量一键融合」的配置记忆，不新增独立节点类型。

## 使用流程

1. 用户添加节点，调整生成设置中的比例或分辨率。
2. 修改后立即保存该节点当前的两项设置，无需点击生成。
3. 下次新建同类型节点时，自动带入上次保存的设置。其他类型的节点仍使用各自记录。

- 没有记录时，默认使用「自动、2K」。
- 仅打开、新建、复制、撤销重做或补充素材，不更新记忆；再次选择相同值也不更新。
- 已有节点保留自己的设置，不随记忆变化。复制节点保留被复制节点的设置；删除主图后再补主图，也保留原节点的设置。
- 读取记录时，某一项已不受支持，则新建节点的该项使用默认值；另一项仍使用有效记录，不改写原记录。

## 一键融合自定义比例

- 比例菜单按 Figma `202:12611`、`202:12857`、`202:13027` 提供默认、输入中、已确认三种状态。
- 菜单首项为「自定义」宽高比，随后为自动、1:1、2:3、3:2、4:3、3:4、4:5、5:4、9:16、16:9。
- 宽高填写正整数，点击「确认」或按 Enter 后应用；未确认关闭菜单时不保存。
- 没有历史记录时默认自动；确认后的自定义比例记入一键融合设置。自定义比例即使与预设相同，仍显示为自定义。
- 复制、撤销重做及恢复保留已确认设置；其他节点的比例菜单不变。
- Demo 沿用固定示例图片，不将比例设置视为实际 AI 输出尺寸。

## 定向融合生成设置

定向融合增加与一键融合一致的「生成设置」区域，提供比例和分辨率选择。

- 比例：自动、1:1、3:4、4:3、9:16、16:9。
- 分辨率：1K、2K、4K。
- 区域位于融合点下方、生成按钮上方，复用现有控件与中英日文案；节点高度增加 72px。

## Demo 存储范围

- 当前 Demo 没有真实账号接口，按同浏览器、同源保存。刷新页面、新建项目或在同源其他标签页新建同类型节点时，均可读取已保存设置。
- 记录使用 `lc-v56-generation-settings:demo-account:<kind>`，四种类型各自保存。这不是账号级或跨设备同步。
- 浏览器存储失败时，最新设置保留在本次页面会话内，仍可用于后续新建节点；刷新后的恢复依赖存储成功。

## 实现位置

- `src/generation-settings-memory.ts`：按类型读写、字段有效性判断及存储失败时的会话保留。
- `src/canvas.ts`、`src/App.tsx`、`src/workflow-examples.ts`：新建时带入、手动修改时保存，以及已有节点设置保留。
- `src/components/DirectedFusionNode.tsx`：定向融合的比例和分辨率控件。
