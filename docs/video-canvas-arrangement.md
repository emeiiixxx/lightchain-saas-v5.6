# 视频工作台：整理画布

视频工作台与万能穿搭融合共用 [Flow 画布整理规则](flow-canvas-arrangement-rules.md)，仅整理画布上展示的图片、视频、编辑器及生成结果；仅在节点内显示的参考素材不参与。按连接分层、实际输入与分支居中、80/120/240 间距、每行最多 5 组、排序与整体避让均保持一致。

独立素材和空节点放在节点组下方，两区间距 240。点击整理时，以当前画布可用宽度除以当前缩放比例，计算每行宽度；按加入顺序和实际宽度从左向右排列，下一项放不下才换行，每行不限数量。行高取该行最高元素，横向及行间距均为 40（画布坐标）。节点组仍每行最多 5 组，组间及换行间距 240；上传后的初始摆放规则不变。

从素材工具栏创建素材生成、视频生成及视频高清放大节点时，节点放在所选素材整体区域右侧 80 并垂直居中，允许重叠；需要重排时点击「整理画布」。

## 视频来源与排序

- 上传的图片、视频按各自加入画布的顺序记录原始上传序。
- 服装短视频结果继承主图的原始上传序，尾帧不参与该排序依据。
- 专业服装视频等多输入结果取实际输入来源的最早上传序；素材生成和高清放大结果沿用对应来源，连续生成继续继承。
- 无输入生成的结果使用自身加入画布的顺序。已有组补素材或生成结果，不改变原组排序。
- 同一来源时间的组按建组先后排列；跨组依赖仍优先保证上游在前。

## 数据边界

`VideoLayoutState` 随画布快照与撤销历史保存：

| 字段 | 用途 |
|---|---|
| `order` / `nextOrder` | 各素材与节点的加入顺序。 |
| `owners` | 当前节点组归属。 |
| `originOrder` | 每个媒体实例首次出现时固定的原始来源序。 |
| `groupOrder` | 首次建组确定的排序依据，追加内容不重算。 |
| `groupCreatedOrder` | 来源时间相同时按建组先后排序。 |
| `originVersion` | 标识组排序已按原始来源序迁移。 |

生成占位创建时记录来源序，完成后沿用原 ID；换输入、删除来源不改变已有结果的继承值。完全断开的素材与空节点进入独立区；删除、撤销和重做同步恢复归属与位置。分组仅服务整理，不新增用户可见的分组容器。

当前 Demo 未接入画布项目存储服务，不承诺刷新后恢复。旧快照缺少来源元数据时按现存连接回填；来源已丢失时保留旧排序值，无法还原未记录的历史上传时间。

实现入口：`video-layout-groups.ts`（归属及来源序）、`video-workflow-layout.ts`（关系解析）、`canvas-connected-layout.ts`（组内连接布局）、`canvas-group-placement.ts`（跨组输入及放置）、`canvas-layout-stages.ts`（阶段顺序）、`VideoWorkspace.tsx`（快照与交互）。
