# 视频描述：智能扩写开关

短视频、长视频节点的视频描述标题右侧显示「智能扩写」，默认关闭。放大输入框的标题区显示同一个开关；两处同步当前节点的设置。输入框底部保留展开、保存、提示词库和字数，放大后保留保存、提示词库、字数与清空。

控件复用 `src/components/Switch.tsx` 与 `switch.css`。`VideoWorkflowNode` 将同一开关传入 `PromptTools.expandedHeaderAction`，同步显示在放大框标题区。

## 状态与交互

- 状态存于当前 `VideoWorkflow` 的 `smartExpand` 字段；未保存此字段的节点按 `false` 显示。
- 点击开关或按 Space／Enter 切换，沿用节点配置的撤销、重做；不同节点独立保存。
- 开启或关闭只更新配置，不改写输入内容、不发起 AI 请求。描述仍必填，最多5000字；上传素材及生成参数保持原规则。
- 输入、清空和应用提示词不改变开关状态。开关不显示「提示词生成／提示词扩写」文案，也不播放扫光效果。

## 尺寸与状态颜色

| 元素 | 规则 |
| --- | --- |
| 开关 | S，32×18px，圆角999px |
| 圆钮 | 14×14px，内缩2px，开启后向右移动14px |
| 标签行 | 高20px、图文间距4px、左右内边距4px；文字12/20px、字重500。节点内用Text/tertiary，放大输入框顶部用Text/on-brand-white，深浅主题一致 |
| 关闭 | Border/medium 背景、1px Border/weak 内描边 |
| 开启 | Brand/primary 背景，无描边；悬停用 Brand/primary-hover |
| 圆钮颜色 | Control/fill/white；阴影为0 6px 14px -2px Overlay/weak |
| 禁用 | 整体不透明度40%，不可切换 |

颜色读取现有语义 token，支持深浅主题。圆钮位移及状态颜色使用200ms ease-out；系统减少动态效果时立即切换。使用可聚焦的 switch 语义及 `aria-checked`，操作开关不拖动画布节点。
