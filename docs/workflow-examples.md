# 画布初始化功能示例

空画布点击一键融合、定向融合、内衣试衣、转3D平铺后，直接展示「主图 → 对应编辑节点 → 示例结果」。不先要求选择素材，用户可以先理解流程，再编辑配置。

| 入口 | 预填内容 |
| --- | --- |
| 一键融合 | 用户提供的乳白色蕾丝家居服套装主图、完整复古卧室时尚社论提示词，不预置参考图，结果使用用户提供的复古卧室模特上身图 |
| 定向融合 | 黄裙模特棚拍、蓝色花裙平铺、一个融合点和示例蒙版、保留人物背景的蓝裙结果 |
| 内衣试衣 | 用户提供的黄紫拼色内衣套装、金发模特参考、对应试衣描述及同款上身结果（模特参考使用screenshot-20260916-181809.png，结果使用screenshot-20260916-180851.png） |

| 转3D平铺 | 用户提供的黑白水手领连身装模特主图、对应平铺结果；选择区域默认连身装，生成面默认正面，生成设置自动 / 2K |

配置集中维护在 `src/workflow-examples.ts`，定向融合配套图片使用内置 image_gen 预生成，一键融合、内衣试衣与转3D平铺直接使用用户提供的原图，存放于 `public/assets/workflow-examples/`，完整提示词记录在 `docs/workflow-example-images.json`。网页本身不调用生成服务，不写真实生成历史。图片按原始比例载入；节点连接沿用 editorSourceId / generatedByEditorId。载入后调用现有整理和适应视图，整组可一次撤销；后续修改、拖拽、生成、删除、整理均沿用画布能力。

节点点击生成也按功能复用对应的配套结果图，以宽360、原图比例显示（一键融合与转3D平铺结果1792×2400，内衣结果794×1064，定向融合结果1024×1536），不再统一输出超现实海岛图。这仍是固定演示素材，不根据用户后续编辑内容生成真实结果。

读取期间禁止重复触发入口；载入失败保持空画布并允许重试。新上传或切换页面时，过期的示例载入不会覆盖新内容。

抠图初始化行为保持原样。转3D平铺节点及空状态见 `docs/flat-lay-node-source.json`。单图工具栏仍对当前图片创建节点，补主图仍打开单选素材弹窗。未运行浏览器、构建或测试检查。
