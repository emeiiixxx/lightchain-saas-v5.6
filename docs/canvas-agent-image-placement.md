# C01｜图片落位

优先级：P0。范围：设计生产工作台 Canvas 的图片添加、生成及发送至画布。

图片按实际像素展示。图片添加及同批横向排列间距80px；Agent每轮首图、重叠后下移及图片工具整批落位间距240px。间距按画布100%计算，文件名空间另计。

落位计算覆盖可视范围内外的图片、文本、形状、线段及生成中、失败占位。

## 添加图片落位

- 底部工具栏／资产：
  - 空画布居中摆放；
  - 已有内容时，放在全部内容下方并左对齐；
  - 整理后再次添加，以整理后的最下沿为准；
- 空白处右键添加：
  - 首张左上角落在右键位置；
  - 拖入已有内容画布落在松手位置；拖入空画布居中。
  - 两者不避让、不改变视角；
- 排列
  - 同批图片从左到右、顶部对齐，不自动换行；添加后选中整批。

## 生图落位（Agent／图片工具）

- 首次落位：本轮首次占位放在画布全部元素下方240px，与全部元素整体左边界对齐；空画布居中。
- 排列：同轮图片从左到右、顶部对齐，间距80px。
- 生成方式：
  - Agent：逐张生成，当前图片尺寸确定后显示占位；本张结束后再开始下一张，接上一张右侧。
  - 图片工具：尺寸确定后，一次显示整批占位。
- Agent 后续图片重叠：只将新图移至当前全部元素下方240px，横向位置不变。
- 已有元素保持原位。

## 发送至画布

- 已在画布中的结果仅聚焦，不重复添加；缺失结果按 Agent 新一轮图片规则补入，并选中、聚焦新增图片。

## 聚焦与生成完成

- 底部／资产添加聚焦整批新图；Agent 仅在本轮首张占位出现时聚焦；图片工具生图聚焦整批占位。聚焦包含文件名，避开侧栏及固定工具栏，最高100%。
- 生成成功按实际尺寸原位替换，失败原位保留；后续逐张出图及生成完成不再次聚焦，完成时不重新排列。
- 聚焦动效为200ms ease-out；减少动态效果时直接到位。
