# C01｜图片落位

优先级：P0。范围：设计生产工作台 Canvas 的图片添加、复制粘贴、生成及发送至画布。

待确认：占位按实际像素展示，需要后端返回最终出图像素。显示占位前确定最终输出宽高，占位与成功图片尺寸一致。

图片添加及同批横向排列间距参考80px；Agent每轮首图、重叠后下移及图片工具整批落位间距参考240px。以上按画布100%时的视觉距离计算，文件名空间另计。

落位计算覆盖可视范围内外的图片、文本、形状、线段及生成中、失败占位。

## 添加图片落位

- 底部工具栏／资产：
  - 空画布居中摆放；
  - 已有内容时，放在全部元素下方80px，与全部元素整体左边界对齐；
  - 整理后再次添加，以整理后的最下沿为准，左对齐；
  - 添加后选中整批，内容移入可视范围。
- 从右键菜单或拖入画布添加：
  - 首张左上角落在右键位置；
  - 拖入有元素内容的画布：落在松手位置；拖入空画布居中。
  - 两者不避让、不改变视角；
- 排列
  - 同批图片从左到右、顶部对齐，间距80px，不自动换行；添加后选中整批。

## 复制粘贴落位

- Ctrl+C／Ctrl+V（Mac为Command+C／Command+V）：副本或整批边界左上角落在鼠标对应画布位置，多选保持相对位置，不重新横排。
- 鼠标不在画布内时使用当前可视画布中心；右键菜单粘贴使用打开菜单时的位置。
- 选中整批副本，不避让、不改变视角；已有元素保持原位，整批一次撤销，图片名称按C02副本规则处理。

## 生图落位（Agent／图片工具）

- 首次落位：本轮首次占位放在画布全部元素下方240px，与全部元素整体左边界对齐；空画布居中。
- 排列：同轮图片从左到右、顶部对齐，间距80px。
- 生成方式：
  - Agent：逐张生成，当前图片尺寸确定后显示占位；本张结束后再开始下一张，接上一张右侧。
  - 图片工具：尺寸确定后，一次显示整批占位。
- Agent 后续图片重叠：只将新图移至当前全部元素下方240px，横向位置不变。
- 已有元素保持原位。

## Agent 图片任务发送至画布（每次1张）

- 已在画布中的结果：选中并移入可视范围，不重复添加。
- 不在画布中的结果：按新一轮首图规则补入，选中并移入可视范围。

## 视角移动与生成完成

- 底部／资产添加后，将新内容移入可视范围。
- Agent 仅在本轮首张占位出现时，将该张占位移入可视范围；图片工具在整批占位首次出现时，将该批内容移入可视范围。
- 底部工具、资产添加、上述生图入口及发送至画布：当前缩放比例能完整展示本次内容时，只平移；放不下时缩小至完整展示，不主动放大，也不适应整个画布。发送至画布只计算本次发送的单张图片；文件名计入展示范围，并避开侧栏及固定工具栏。
- 生成成功按实际尺寸原位替换，失败原位保留；Agent 后续逐张出图不再次调整视角，生成完成不再次调整视角或重新排列。
- 添加图片保持200ms ease-out过渡；通过图片选择窗口添加时，先收起窗口再开始移动视角。
- 生成及发送至画布时平滑过渡，距离越远，过渡时间越长。
- 手动拖动、滚轮或小地图操作立即接管视角；新的视角移动从当前视角继续。减少动态效果时直接到位。
