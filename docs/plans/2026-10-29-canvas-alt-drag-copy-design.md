# Canvas 拖动复制

对应需求：C05｜拖动复制。优先级：P2，已同步 v5.6 飞书产品文档。

## 操作

- 选择模式下，按住Alt／Option并用鼠标左键拖动元素。
- 原件不动，副本随鼠标移动；松手后选中副本，整批一次撤销。
- 支持图片、形状、多选及编组；多选保持相对位置，新编组与原组独立。
- 只有点击、没有拖动时不复制。开始复制后松开Alt／Option，仍完成本次复制。
- Esc、窗口失焦或指针取消时移除本次副本；原件及其他任务不受影响。

## 边界

- 沿用选择规则：拖动已选元素复制当前选区，拖动未选元素复制该元素或所属组。
- 生成中、失败占位不复制。抓手、空格／中键平移及形状绘制不触发复制。
- 副本保留外观，图片文件名按C03在格式后缀前添加「_副本」，同名副本按最大序号递增为「_副本2、_副本3…」；复制副本不重复叠加标识，生成图片不占用新的生成编号。
- 副本使用新对象／编组ID，不继承任务身份或项目封面；保存、恢复及撤销重做保留副本名称。
- 拖动直接跟手，不添加位置缓动；临时副本不写入存储，松手后记录历史。
- 快捷键面板「元素」区增加拖动复制说明，Mac显示Option，其他平台显示Alt。
