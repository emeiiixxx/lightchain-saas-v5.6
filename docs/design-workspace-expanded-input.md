# 底部输入框自动撑高

## 适用范围

适用于设计生产工作台底部多模态输入框中，局部编辑、AI 试衣的正文输入模式，不显示放大或还原按钮。

印花上身、右侧 Agent 对话输入与浮动快捷编辑保持原交互。

## 自动高度

- 默认面板为 800×276px，正文高 64px。
- 输入、粘贴或应用提示词后，正文随内容向上撑高，面板最高 400px，正文最高 188px。
- 达到最大高度后，仅正文区域内部滚动；顶部素材区与底部操作区保持可见。
- 删除内容后自动回缩，最低回到默认高度。
- 面板宽度及底部位置保持不变；高度变化不移动或缩放画布视图。

## 编辑与关闭

- 高度变化不影响正文、参考素材、素材顺序和参数，可继续编辑正文、添加或调整参考素材及设置参数。
- 自动调整高度不触发生成，字数、素材数量限制及提交规则沿用原功能。
- Esc 沿用工具关闭逻辑：有子浮层时先关闭子浮层，否则关闭工具。标题栏关闭按钮仍关闭整个面板。

尺寸与视觉参考 [Figma 6:11797](https://www.figma.com/design/A3oI9FzDPseUH4ybk7mA3H/Lightchain-SaaS-v5.6.0?node-id=6-11797&m=dev)、[Figma 6:11904](https://www.figma.com/design/A3oI9FzDPseUH4ybk7mA3H/Lightchain-SaaS-v5.6.0?node-id=6-11904&m=dev)。当前交互采用自动撑高，设计稿中的手动放大／还原按钮不展示；来源及覆盖规则记录于 `design-workspace-input-source.json`。

Demo 基于 v5.4 设计生产工作台副本演示，通过顶栏「设计生产工作台」进入 `#/design-workspace`；原 v5.4 项目保留。该入口用于演示本次交互，生成能力及其他工作台规则沿用原功能。

首次进入时加载独立工作台；切换页面保留其画布和输入草稿，主题与语言随顶栏同步。工作台使用 `lc-v56-design` 存储前缀，与融合画布及视频工作台的数据隔离。源码副本位于 `src/design-workbench`，素材位于 `public/assets/design-workbench`，构建入口为 `design-workbench/index.html`。
