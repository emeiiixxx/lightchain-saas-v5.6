# 融合画布生图任务

适用于一键融合、定向融合、内衣试衣、合拼生图、批量编辑及转3D平铺，包括结果工具栏的重新生成。

| 操作或状态 | 画布与任务列表 |
|---|---|
| 点击生成且输入有效 | 在画布添加结果占位；每张结果在任务列表独立显示一条记录，批量生成也不合并，进行中数量按结果条数统计。 |
| 演示生成完成 | 3秒后原位替换为示例结果，保留当前尺寸、位置、连接和排序；每条记录显示「生成完成」、提交时间及对应结果的缩略图和文件名，不再次移动画布。 |
| 点击已完成记录 | 只选中并按200ms ease-out聚焦该条对应的结果；任务列表保持展开。 |
| 聚焦后点击画布空白 | 取消当前选择；选择工具和抓手工具均支持。拖动画布只平移，素材选择流程保持原规则。 |
| 删除部分批量占位 | 只完成剩余占位，不补回已删内容。 |
| 删除编辑器或全部占位 | 停止该任务并显示失败；撤销或重做不重新启动计时。 |
| 撤销、重做 | 生成提交记录一次画布历史；任务记录单独保留，恢复旧占位时使用该任务最终状态。 |
| 删除完成结果 | 保留对应记录、缩略图和最后文件名，该条暂不可聚焦；撤销恢复结果后可再次聚焦，其他记录不受影响。 |

- 进行中和失败占位可拖动、整理、删除，不可下载、复制、预览或作为新节点输入。
- 复制、抠图产生的内容不属于原生图任务，点击原任务不会跳转到副本。
- 万能穿搭融合和视频工作台共用逐结果展示规则；同批生成仍共用原任务生命周期及一次提交、一次撤销。
- 任务列表展开后的整体高度最多380px（含标题栏），超出时仅内容区滚动；可用屏幕高度不足时进一步缩小。
- 切换工作台后任务继续完成，不移动隐藏画布或抢占焦点。
- 仅记录本次页面会话内新提交的任务，不将初始化示例补成历史任务。刷新后不恢复；仍为本地演示，不调用真实AI或扣费。

## 任务列表样式

来源：Figma v5.6 `74:20493`，万能穿搭融合与视频工作台共用。

- 面板宽240px，展开整体最高380px；标题栏高40px，超出部分在内容区滚动。
- 记录高80px、圆角12px、内边距8px；缩略图64×64px、圆角4px，与文字相距10px。内容区内边距12px，记录间距8px。
- 从上到下显示文件名、状态、提交时间，均为12/16px，行间距4px。文件名使用次级文字色与Medium字重，单行省略并可悬停查看全名；状态使用三级文字色，时间使用占位文字色与Regular字重。
- 生成中记录显示预分配文件名及3秒线性循环的原始渐变动效；仅完成且结果仍存在时支持双击改名。画布生成中、失败占位仍不显示文件名。
- 沿用深浅主题、200ms展开收起缓动及减少动态效果支持。设计来源及原始素材见 `docs/canvas-task-list-source.json`。
