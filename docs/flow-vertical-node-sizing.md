# F10｜竖向节点编辑器尺寸调整

优先级：P2。

适用范围：Flow 类型画布的所有竖向节点编辑器，含万能穿搭融合、视频工作台。尺寸以画布 100% 缩放为基准。

## 编辑器

- 竖向节点编辑器宽度统一为 320px，新建与已有节点均适用。
- 内部内容随宽度适配，选框、连线及排列按新尺寸计算。

## 参考图区

- 正方形「＋」添加入口及对应缩略图统一为 64×64px。
- 网格每行 4 个，间距 8px。
- 一键融合、合拼生图参考图区最大高度 208px，超出内部滚动；删除按钮保留外移空间。

## 设计来源与 Demo 范围

[Figma 73:18017](https://www.figma.com/design/A3oI9FzDPseUH4ybk7mA3H/Lightchain-SaaS-v5.6.0?node-id=73-18017&m=dev)。

融合画布的一键融合、合拼生图、定向融合、内衣试衣、转3D平铺及批量转3D平铺采用 320px 宽度；视频工作台沿用已符合的 320px 节点与 64px 方形入口。横向批量编辑器仍为 592px，矩形主图入口和定向点预览保持原样。

布局尺寸由 `src/canvas.ts` 的 `workflowWidth`、`workflowHeight` 提供，与 `src/fusion-node.css` 同步；参考图按 64px 高加 8px 行间距计算节点高度。更新尺寸不主动移动已有内容或调整视角。
