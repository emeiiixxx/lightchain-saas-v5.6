# Flow 画布整理规则

适用于万能穿搭融合与视频工作台的图片、视频、编辑器及生成结果。点击「整理画布」整理整个画布，选区不限制范围。

**独立素材**：未与其他素材或编辑器建立关联的图片、视频等素材。**整体中心**：参与对象最上边缘与最下边缘之间的中点，按实际尺寸计算。

## 确定节点组

| 节点输入 | 处理方式 |
|---|---|
| 均为独立素材 | 素材、新编辑器及其结果组成一组，不按上传批次拆分。 |
| 引用 1 个已有组，可包含独立素材 | 新素材、编辑器及结果加入该组。 |
| 引用 2 个及以上已有组，可包含独立素材 | 新素材、编辑器及结果另成一组；旧素材保留原组，通过连线引用。 |
| 向已有节点补充独立素材 | 新素材加入该节点所在组，不改变原组排序。 |

同一画布素材只摆放一次，不为排版复制或改变归属；批量编辑的共享参考图不参与分组。不同画布 ID 的素材分别处理，即使文件相同。

## 顺序与层级

- **组排序**：按主图原始上传时间从早到晚排列，多张主图取最早一张。已有组补充素材、节点或结果，保持原组顺序。
- **生成结果作输入**：沿用原主图上传时间，多轮生成继续继承；批量结果逐张继承对应主图，合拼结果取多个来源的最早时间。继承时间确定后，不因换输入或删除来源改变。
- **跨组连接**：先上游、后下游，后上传素材形成的独立新组排在已有流程之后。例如已有 A、B→C，后加独立 D，排列为 A、B→C、D。
- **从左向右**：按「输入素材→编辑器→结果→后续节点」排列，不要求所有最终结果处于同一列。
- **上下顺序**：输入素材按节点内列表顺序；同一来源的多个后续节点或结果按创建顺序。已有流程中的素材保留原连接层级；共享素材不因后续引用重新排列原流程。
- **新增输入**：放在流程中最靠前的使用节点左一列，与同列旧结果上下排列。例：旧融合结果和新花纹图共同输入合拼，两张输入同列，不能把花纹图排成旧结果之后的下一步。

## 居中与间距

| 情况 | 对齐方式 |
|---|---|
| 单线流程 | 素材、编辑器及结果对齐同一水平中心线。 |
| 多个分支 | 后续节点或结果上下展开，上游对齐直接连接对象的整体中心；各条后续流程分别居中。 |
| 多输入汇合 | 编辑器对齐实际直接连接的输入整体中心，未连接素材不参与计算；单个结果跟随编辑器居中，多个结果按整列中心对齐。 |
| 跨组输入 | 旧素材保留原组，下游优先对齐实际引用的素材范围。 |
| 同行节点组 | 没有跨组输入对齐约束时，各组按整体中心对齐，行高取最高组，不按顶部对齐。 |
| 出现重叠 | 排序靠后的分支或节点组整体向下避让，保留内部相对位置；此时允许偏离上游输入中心。 |

优先级：连接关系、组归属与素材唯一性 → 不重叠 → 居中。

列宽取该列最宽对象，相邻列间距 **80**，纵向分支至少 **120**，组间及换行 **240**，跨组阶段及上下独立区 **480**，均为画布坐标。窄对象到下一列的实际空隙可能大于 80。

每个阶段从左到右排列，每行最多 5 组，第 6 组换行。独立素材与空节点集中放在下方，按加入画布的顺序排列，每行最多 5 个。窗口大小不改变分组与每行数量。

## 新建节点与整理结果

从素材工具栏添加节点时，编辑器放在素材右侧 80 并居中；多选时按所选素材整体边界居中。允许重叠，不自动向下避让，需要重排时点击「整理画布」。

整理不改变素材尺寸、内容、配置、连接关系或选区；完成后适应全部内容，记录一次撤销。内容不变时重复整理位置不变。

生产保存恢复需保留排序时间与组归属。当前 Demo 在画布快照及撤销历史中保存，未接入服务端画布项目持久化。
