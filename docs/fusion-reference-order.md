# F06｜参考图排序与编号

## 适用范围

适用于一键融合、合拼生图节点的参考图。

参考图区尺寸按 F10 与 Figma 73:18017 展示：缩略图及「＋」添加入口均为 64×64px，每行 4 列，间距 8px；内容最大高度 208px，超出时内部滚动。为外移删除按钮保留空间，避免裁切；原有素材展示、删除和最多 9 张的添加规则不变。

## 标题与提示

- 标题依次显示「参考图」、16px 说明图标、1×12px 竖分隔线和「最多9张，已添加 n/9」。
- n 为当前参考图数量，使用品牌色，随添加、删除更新。
- 鼠标悬停或键盘聚焦说明图标时，右侧显示「支持拖拽素材调整顺序」。复用现有 Tooltip，不使用原生标题提示；排序仍只支持鼠标拖拽。
- 添加入口使用设计稿中的 20px 加号 SVG，最多添加 9 张参考图。

## 编号

- 每张缩略图左下角显示编号，从 1 开始连续排列；只有一张时也显示 1。
- 编号样式沿用视频工作台：距左侧及底部各 4px，20px 品牌色圆形，文字 12/16px。
- 按参考图列表顺序，从左到右、逐行编号。
- 新添加的参考图排在末尾；删除后重新连续编号，不留空号。

## 调整顺序

- 仅支持鼠标拖拽排序，可跨行调整位置，相邻项以 200ms ease-out 移动让位。
- 拖动过程中只预览顺序和编号，不保存；松手后立即应用最终顺序和编号，不追加落位动画。
- 最终顺序发生变化时，整次改序记录一次撤销；撤销恢复原顺序及编号。
- 取消拖拽或拖出后未落入有效位置时，恢复原顺序，不产生撤销记录。

## 删除按钮

- 沿用视频工作台样式：24px 圆形按钮，位于缩略图右上角，向上、向右各外移 8px。
- 使用 12px 白色关闭图标、Tonal 深色半透明底和背景模糊。
- 悬停或聚焦时显示，拖拽排序时隐藏；缩略图外层不裁切按钮。
- 原有删除行为保持不变。

## 素材与画布关系

只改变当前节点的参考图输入顺序。参考图的 `id`、`url`、`sourceImageId` 及对象身份保持不变；不移动画布素材，不修改引用或自动连线，也不把参考图改为主图。
