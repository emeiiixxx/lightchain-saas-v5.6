## 滚轮参数与输入归一化

实现：`src/design-workbench/viewer-wheel-zoom.ts`。只影响设计生产工作台的大图窗口，不改画布平移／缩放处理。

| 输入 | 规则 |
| --- | --- |
| 可识别的刻度滚轮 | 每归一化刻度放大 ×1.1、缩小 ÷1.1；整批多刻度按数量计算，零碎刻度先累积。 |
| 连续滑动、捏合及无法明确识别的输入 | 保留原公式 `exp(-deltaPx × 0.0015)`，以及每次滚动量 ±600px 的既有限制。 |

- 根据 `deltaMode` 转换：像素直接使用，行按现有 16px 换算，页按图片查看区域高度换算。
- 不使用操作系统或品牌判断。Ctrl 捏合、带横向分量或小数像素的滑动按连续输入处理；连续手势在 240ms 内保持同一处理方式，避免惯性滚动中途跳成刻度缩放。
- 常见刻度输入使用可选 `wheelDeltaY` 的 120 单位提示；没有该提示时，使用常见的 100／120px 或 3 行步长归一化。仅监听标准 `wheel` 事件。
- 保留以指针位置为缩放中心，以及相对初始适应视图的 0.1–8 倍范围。拖动与滚轮直接跟随输入，不追加 200ms 过渡。

标准滚轮事件不能可靠给出硬件型号；上述是保守的输入特征适配，不能保证覆盖所有鼠标、驱动和浏览器组合。普通滚轮、Magic Mouse 和触控板的实际手感仍需按 PRD 联调确认。
