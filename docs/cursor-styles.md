# SaaS v5.3 指针样式清单

| 操作场景 | 指针样式 |
|---|---|
| 选择工具下，移入画布空白处或不可操作区域 | 默认箭头 |
| 移入／拖动图片 | 四向移动箭头 |
| 移入节点编辑器可拖动区域 | 张开手掌 |
| 抓手工具／按住空格 | 张开手掌 |
| 拖动画布或节点编辑器 | 握紧手掌 |
| 移入按钮、菜单选项 | 点击手指 |
| 移入文字输入区 | 文本光标（I 形） |
| 拉伸输入框四角 | 对应方向的双向箭头 |
| 移入小地图空白处 | 十字光标 |
| 移入小地图可视框 | 张开手掌，拖动时握紧 |
| 抠图涂抹 | 与笔刷大小一致的圆形光标 |
| 抠图套索 | 套索专用指针 |
| 抠图钢笔 | 钢笔专用指针 |
| 抠图框选 | 十字光标 |

切换工具、结束拖动或退出操作后，恢复对应指针，避免状态残留。节点内按钮和输入框使用各自的指针；弹窗内操作不影响底层画布指针。
